=========================================================
 KHANA KHAZANA — RESTAURANT & CAFE · WEBSITE PACKAGE
=========================================================

A complete, ready-to-publish one-page website for
Khana Khazana Restaurant & Cafe, Civil Lines, Prayagraj.

---------------------------------------------------------
 HOW TO VIEW
---------------------------------------------------------
Simply double-click  index.html  — it opens in any browser.
No server, no build tools, no internet setup required
(fonts load from Google Fonts when online; everything else
is local).

Keep index.html and the images/ folder together.

---------------------------------------------------------
 HOW TO PUBLISH (any of these work)
---------------------------------------------------------
1. cPanel / shared hosting: upload index.html + images/
   to your public_html folder. Done.
2. Netlify / Vercel / GitHub Pages: drag-and-drop this
   folder onto their dashboard. Free.
3. Cloudflare Pages: upload this folder as a project.

---------------------------------------------------------
 WHAT'S INSIDE
---------------------------------------------------------
index.html   — the whole website (HTML + CSS + JS, no deps)
images/      — 8 custom food & interior photographs
README.txt   — this file

---------------------------------------------------------
 QUICK EDITS (open index.html in Notepad / VS Code)
---------------------------------------------------------
• Phone number: search for  +918858682467
• Address:      search for  Tashkent Marg
• Hours:        search for  11:00 AM
• Menu items & prices: scroll to the MENU <script> section
  near the bottom — items are plain lists, easy to edit.
• Reviews / dish descriptions: plain HTML text, search
  and replace.

---------------------------------------------------------
Design: deep pine + saffron palette, Fraunces serif
display type, scroll animations, tabbed menu, gallery,
Google reviews and one-tap directions + call buttons.
Fully responsive for mobile and desktop.
